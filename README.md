# ESP32 Alexa Smart Home Automation

This project is a voice-controlled smart home automation system developed using ESP32 and Amazon Alexa integration through the Sinric Pro platform.

The system allows users to control multiple smart devices using voice commands. Device states are synchronized through the cloud and displayed on an OLED screen in real time.

## Features

- Amazon Alexa voice control
- ESP32 Wi-Fi connectivity
- Sinric Pro cloud integration
- OLED status dashboard
- Smart lighting control
- Smart fan control
- Smart pump control
- Servo motor automation
- Physical button override
- Real-time device monitoring

## Hardware Components

- ESP32 DevKit
- OLED SSD1306 Display
- Servo Motors
- Push Buttons
- LED Indicators
- Potentiometer
